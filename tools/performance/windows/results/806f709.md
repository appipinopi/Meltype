# Windows共通Coreの速度比較（806f709）

測定対象は `806f7091f656cc2a84206945fba9c9a8416e54e2` のRust Releaseと、元版 `45e14f86558aa6ea34f2c2ecd038ba95ca8c3c46` のC# NativeAOTです。
同じ辞書・設定で、各ケースをウォームアップ1回＋測定3回、実行順を逆にした2巡（計6試行）測定しました。測定前後のソースと実行ファイルは不変、他のビルドは並行実行していません。

**確定内容・全打鍵の途中状態とも21/21一致**。前版の7件の不一致は修正済みです。対象は消費状態・確定編集・表示文字・変換状態で、候補一覧・全設定・画面描画の一致を示しません。
