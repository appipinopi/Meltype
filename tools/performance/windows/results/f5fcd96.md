# Windows共通Coreの速度比較（f5fcd96）

測定対象は `f5fcd963f093820308043e7b9851ff481a34d7e4` のRust Releaseと、元版 `45e14f86558aa6ea34f2c2ecd038ba95ca8c3c46` のC# NativeAOTです。
同じ辞書・設定で各ケースをウォームアップ1回＋測定3回、実行順を逆にした2巡（計6試行）測定しました。測定前後のソースと実行ファイルは不変、他のビルドは並行実行していません。

**確定内容・全打鍵の途中状態とも21/21一致**。137テスト、Windows Release DLLの元版63入力（2,530打鍵）も成功した版です。比較対象は消費状態・確定編集・表示文字・変換状態で、候補一覧・全設定・全画面の一致を示しません。

音の区切りでの不要な辞書照会と、URLスキームの終端の繰り返し走査を削減しました。下記は入力列全体の中央値で、文字数に加えて末尾のEnterを含みます。起動・辞書初期化・OS配送・画面描画・変換器・ファイルI/Oは測定外です。
