# Windows共通Coreの速度比較（9b28322）

測定対象は `9b28322021a2d1aa3795d3de3e72d3237b64ace0` のRust Releaseと、基準コミット `45e14f86558aa6ea34f2c2ecd038ba95ca8c3c46` のC# NativeAOTです。
同じ同梱辞書を使用し、学習・予測・ライブ変換・OSスペル辞書を無効にしました。変換器、ファイルI/O、起動・セッション／辞書初期化は測定外です。
各ケースにつきウォームアップ1回と測定3回を行い、実行順を逆にしてもう1巡しました（計6試行）。本端末でのキー処理とJSON生成の値で、実OSのIMEや画面描画の速度ではありません。

最終確定は **19/21**、途中状態までの一致は **14/21** です。判定するのはconsumed、確定編集、表示文字、変換状態だけです。候補・注釈・全UIの一致は含みません。
7ケースは同じ動作としての速度評価に採用しません。測定前後のソース・バイナリは一致し、他のビルドは並行実行していません。
