# Windows共通Coreの速度比較（ce689c0）

測定対象は `ce689c09269b57001b8f6b0361acc53859f35abc` のRust Releaseと、元版 `45e14f86558aa6ea34f2c2ecd038ba95ca8c3c46` のC# NativeAOTです。同じ辞書・設定で各ケースをウォームアップ1回＋測定3回、実行順を逆にした2巡（各実装・各ケース6試行）測定しました。測定前後のソースと実行ファイルは不変で、他のビルドは並行実行していません。

**確定内容・全打鍵の途中状態とも21/21一致**。測定は学習・ライブ変換・予測・OSスペル・外部変換器を無効にしたBalancedのメモリ内キー処理とJSON生成です。候補一覧・ヒント・注釈・全設定・全画面の一致、TSF配送・描画・起動・変換エンジン・メモリ消費は対象外です。

この版では、学習を止める設定や入力欄で、確定時に破棄する履歴・日英学習情報を組み立てないようにしました。関連する55テストとRust 1.99のワークスペース／TSF-server Clippyが成功しています。直前のdf38e48では全184テストとx64／x86のRelease回帰が成功しており、今回の測定対象の検証範囲と区別します。
